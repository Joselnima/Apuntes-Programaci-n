# Módulo 15 - ECMAScript 8 (ES2017)

ES8 trajo consigo el cambio más importante para la asincronía en JavaScript, además de nuevas formas de manejar objetos y cadenas.

## 1. Funciones Asíncronas (`async/await`)

Esta es la característica estrella. Permite escribir código asíncrono (basado en Promesas) de una forma que se lee como si fuera sincrónico, evitando el famoso "Callback Hell" o las interminables cadenas de `.then()`.

```javascript
// Usando Promesas (ES6)
function obtenerUsuarioPromesa() {
  fetch('https://api.com/usuario')
    .then(respuesta => respuesta.json())
    .then(datos => console.log(datos));
}

// Usando Async/Await (ES8)
async function obtenerUsuarioAsync() {
  const respuesta = await fetch('https://api.com/usuario');
  const datos = await respuesta.json();
  console.log(datos);
}
```

## 2. `Object.values()` y `Object.entries()`

Métodos útiles para iterar objetos sin tener que usar `Object.keys()` todo el tiempo.

```javascript
const usuario = { nombre: 'Ana', edad: 25 };

console.log(Object.values(usuario)); 
// ['Ana', 25]

console.log(Object.entries(usuario)); 
// [['nombre', 'Ana'], ['edad', 25]]
```

## 3. String Padding (`padStart` y `padEnd`)

Añade caracteres al principio o al final de una cadena hasta alcanzar una longitud específica. Muy útil para formatear números de tarjetas de crédito, horas, etc.

```javascript
const hora = '9';
console.log(hora.padStart(2, '0')); // "09"

const tarjeta = '1234';
console.log(tarjeta.padStart(16, '*')); // "************1234"
```

## 4. Object.getOwnPropertyDescriptors()
Devuelve todos los descriptores de propiedad de un objeto propio. Se usa a menudo junto con `Object.defineProperties()` para clonar objetos copiando también sus configuraciones (como getters y setters).
