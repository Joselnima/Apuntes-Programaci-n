# Curso Completo de JavaScript y ECMAScript moderno

Bienvenido al **Curso Completo de JavaScript**. Este curso está diseñado como un libro práctico y fácil de seguir para programadores que recién comienzan o quieren profundizar en las características más recientes del lenguaje.

## ¿Qué aprenderás?

- Fundamentos de JavaScript paso a paso
- Variables, tipos de datos (Float64, BigInt, TypedArrays)
- Métodos útiles de tipos primitivos (incluyendo métodos de Date)
- Funciones, objetos y arrays (con métodos funcionales avanzados)
- Manipulación del DOM, Formularios y Eventos
- Programación asíncrona y consumo de APIs con `fetch`
- Clases, prototipos y los 4 pilares de la POO
- Formato JSON para intercambio de datos
- Todas las características modernas explicadas año por año (De ES6 hasta ES15/2024)
- Estructuras de datos (Map, Set), RegEx, Manejo de Archivos (File API)
- Utilidades misceláneas y técnicas profesionales de Debugging
- Buenas prácticas, debugging y organización de código
- Un proyecto final para aplicar lo aprendido

1. Lee cada módulo con calma.
2. Copia los ejemplos y pruébalos en tu editor.
3. Haz los ejercicios propuestos.
4. Avanza de forma progresiva, construyendo conocimiento.

> Este curso está escrito para principiantes pero cubre temas muy avanzados. Cada concepto está explicado con ejemplos claros y lenguaje sencillo.
