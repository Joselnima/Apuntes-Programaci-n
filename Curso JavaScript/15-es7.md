# Módulo 14 - ECMAScript 7 (ES2016)

ES7 fue una actualización menor en comparación con ES6, pero introdujo dos características que mejoraron enormemente la calidad de vida de los desarrolladores.

## 1. `Array.prototype.includes()`

Antes de ES7, para saber si un arreglo contenía un elemento, usábamos `indexOf() !== -1`. `includes()` hace esto mucho más legible y devuelve un booleano directo.

```javascript
const mascotas = ['perro', 'gato', 'loro'];

// Antes (ES6 y anteriores):
if (mascotas.indexOf('gato') !== -1) {
  console.log('Tienes un gato');
}

// Ahora (ES7):
if (mascotas.includes('gato')) {
  console.log('Tienes un gato');
}
```

Además, `includes()` maneja correctamente los valores `NaN`, a diferencia de `indexOf`.

## 2. Operador de Exponenciación (`**`)

Antes, para elevar un número a una potencia, usábamos la función del objeto global `Math`. ES7 trajo un operador matemático nativo para esto.

```javascript
// Antes:
const alCubo = Math.pow(2, 3); // 8

// Ahora (ES7):
const alCuboModerno = 2 ** 3; // 8
```

Este operador también soporta asignación compuesta (`**=`):
```javascript
let base = 3;
base **= 2; // base ahora es 9
```
