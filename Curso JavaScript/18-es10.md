# Módulo 17 - ECMAScript 10 (ES2019)

ES10 trajo métodos nativos largamente esperados para manipular arrays y strings, además de pequeños ajustes a la sintaxis del lenguaje.

## 1. `Array.prototype.flat()` y `flatMap()`

`flat()` crea un nuevo array con todos los elementos de sub-arrays concatenados recursivamente hasta la profundidad especificada.

```javascript
const numeros = [1, 2, [3, 4, [5, 6]]];

console.log(numeros.flat(1)); // [1, 2, 3, 4, [5, 6]]
console.log(numeros.flat(2)); // [1, 2, 3, 4, 5, 6]
```

`flatMap()` es idéntico a aplicar `map()` seguido de `flat()` de profundidad 1.

```javascript
const frases = ["Hola Mundo", "Adiós"];
const palabras = frases.flatMap(frase => frase.split(" "));
console.log(palabras); // ["Hola", "Mundo", "Adiós"]
```

## 2. `Object.fromEntries()`

Es la operación inversa a `Object.entries()`. Toma una lista de pares clave-valor (como un Array o un Map) y la transforma en un Objeto.

```javascript
const pares = [['nombre', 'Carlos'], ['edad', 28]];
const obj = Object.fromEntries(pares);
console.log(obj); // { nombre: 'Carlos', edad: 28 }
```

## 3. `String.prototype.trimStart()` y `trimEnd()`

Además del ya existente `trim()` que limpia ambos lados, ahora podemos ser específicos.

```javascript
const saludo = "   Hola!   ";
console.log(saludo.trimStart()); // "Hola!   "
console.log(saludo.trimEnd());   // "   Hola!"
```

## 4. Optional Catch Binding

Antes de ES10, estabas obligado a declarar una variable para el error en un bloque `catch`, incluso si no la usabas. Ahora es opcional.

```javascript
// Antes:
try {
  hacerAlgoPeligroso();
} catch (error) { // error era obligatorio
  console.log("Falló!");
}

// ES10:
try {
  hacerAlgoPeligroso();
} catch { // Sin paréntesis
  console.log("Falló!");
}
```
