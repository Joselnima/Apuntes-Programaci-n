# Módulo 20 - ECMAScript 13 (ES2022)

ES13 trajo mejoras en la Programación Orientada a Objetos, sintaxis más limpia para acceder a arrays y flexibilidad en la ejecución de código asíncrono.

## 1. Class Fields (Propiedades Públicas y Privadas)

Antes, para definir propiedades iniciales en una clase, debías hacerlo dentro del constructor. ES13 permite declararlas a nivel de clase.

Además, introduce el **simbolo `#`** para declarar propiedades y métodos verdaderamente privados, los cuales arrojarán un error si se intentan acceder desde fuera.

```javascript
class CuentaBancaria {
  // Propiedad pública a nivel de clase
  banco = "JavaScript Bank"; 
  
  // Propiedad privada
  #saldo = 0; 

  depositar(cantidad) {
    this.#saldo += cantidad;
  }

  obtenerSaldo() {
    return this.#saldo;
  }
}

const miCuenta = new CuentaBancaria();
miCuenta.depositar(100);
console.log(miCuenta.obtenerSaldo()); // 100
// console.log(miCuenta.#saldo); // Error: El campo privado '#saldo' no es accesible
```

## 2. Top-Level `await`

Históricamente, la palabra clave `await` solo podía usarse dentro de una función asíncrona (`async`). Ahora, en módulos modernos de JavaScript (`type="module"`), puedes usar `await` en el nivel superior del archivo.

```javascript
// archivo-modulo.js
// Ya no necesitas envolver esto en un (async () => { ... })()
const respuesta = await fetch("https://api.com/config");
const config = await respuesta.json();
export default config;
```

## 3. Método `.at()` para Arrays y Strings

Permite acceder a los elementos usando índices relativos al final del objeto sin tener que usar `array.length - 1`.

```javascript
const letras = ["a", "b", "c", "d"];

console.log(letras.at(0));   // "a" (Igual que letras[0])
console.log(letras.at(-1));  // "d" (Último elemento)
console.log(letras.at(-2));  // "c" (Penúltimo elemento)
```

## 4. `Object.hasOwn()`

Una alternativa segura a `Object.prototype.hasOwnProperty.call()`. Se usa para verificar si una propiedad le pertenece directamente a un objeto, no a su prototipo.

```javascript
const coche = { marca: "Ford" };
console.log(Object.hasOwn(coche, "marca")); // true
```
