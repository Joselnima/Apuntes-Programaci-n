# Módulo 22 - ECMAScript 15 (ES2024 / Actualidad)

ES15 continúa puliendo el lenguaje, trayendo una de las funciones más esperadas en la manipulación de datos, y utilidades avanzadas para la creación de promesas.

## 1. Agrupamiento de Objetos (`Object.groupBy` y `Map.groupBy`)

Agrupar datos basados en una propiedad es una operación increíblemente común. Históricamente teníamos que usar `reduce()` o librerías como Lodash (`_.groupBy`). A partir de 2024, JavaScript lo soporta nativamente.

`Object.groupBy()` toma un objeto iterable y una función callback. Agrupa los elementos según la clave que retorne el callback.

```javascript
const usuarios = [
  { nombre: "Ana", rol: "admin" },
  { nombre: "Pedro", rol: "editor" },
  { nombre: "Maria", rol: "admin" },
  { nombre: "Luis", rol: "lector" }
];

const agrupados = Object.groupBy(usuarios, usuario => usuario.rol);

console.log(agrupados);
/* Salida:
{
  admin: [
    { nombre: "Ana", rol: "admin" },
    { nombre: "Maria", rol: "admin" }
  ],
  editor: [
    { nombre: "Pedro", rol: "editor" }
  ],
  lector: [
    { nombre: "Luis", rol: "lector" }
  ]
}
*/
```

## 2. `Promise.withResolvers()`

Es un método estático que crea una nueva Promesa y te devuelve directamente la `promise`, su función `resolve`, y su función `reject` en un solo paso. Es extremadamente útil cuando necesitas resolver una promesa desde un lugar lejano en el código o envolver APIs basadas en eventos.

```javascript
// ES6 (Antigua forma tediosa):
let resolverExterna;
const promesaVieja = new Promise((resolve, reject) => {
  resolverExterna = resolve;
});

// ES15 (Nueva forma limpia):
const { promise, resolve, reject } = Promise.withResolvers();

// Ahora puedes usar 'resolve' en cualquier otra parte o evento
document.getElementById('boton').addEventListener('click', () => {
  resolve("Botón fue clickeado!");
});

promise.then(mensaje => console.log(mensaje));
```

## Resumen Final

El ciclo de lanzamiento de ECMAScript es anual. Lo que comenzó como una reestructuración masiva en ES6 (2015), ahora se trata de agregar mejoras constantes de calidad de vida cada junio. Mantenerse al tanto de estas nuevas funciones te permite escribir un código más corto, menos propenso a errores y, sobre todo, mucho más limpio y profesional.
