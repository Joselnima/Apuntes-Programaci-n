# Módulo 16 - ECMAScript 9 (ES2018)

ES9 trajo grandes mejoras en el manejo de objetos, iteración asíncrona y promesas.

## 1. Propiedades Rest y Spread para Objetos

ES6 introdujo rest y spread para arreglos (`...`). ES9 lo expandió a los objetos.

**Rest (Extraer)**
```javascript
const configuracion = { host: 'localhost', puerto: 8080, db: 'mysql', usuario: 'root' };
const { host, puerto, ...restoConfig } = configuracion;

console.log(restoConfig); // { db: 'mysql', usuario: 'root' }
```

**Spread (Clonar y Combinar)**
```javascript
const base = { a: 1, b: 2 };
const extendido = { ...base, c: 3 }; // { a: 1, b: 2, c: 3 }
```

## 2. Iteración Asíncrona (`for await...of`)

Si tienes un arreglo de Promesas (o cualquier objeto iterable asíncrono), ahora puedes iterar sobre él esperando la resolución de cada uno secuencialmente.

```javascript
async function procesarPromesas(arrayDePromesas) {
  for await (const resultado of arrayDePromesas) {
    console.log(resultado);
  }
}
```

## 3. `Promise.prototype.finally()`

Un bloque que se ejecuta independientemente de si la promesa se resolvió correctamente (`.then()`) o fue rechazada (`.catch()`). Es ideal para ocultar pantallas de carga o cerrar conexiones de bases de datos.

```javascript
mostrarPantallaCarga();

fetch('https://api.com/datos')
  .then(res => res.json())
  .catch(err => console.error(err))
  .finally(() => {
    // Esto siempre se ejecuta
    ocultarPantallaCarga(); 
  });
```

## 4. Mejoras en Expresiones Regulares (RegEx)
ES9 introdujo los grupos de captura nombrados en RegEx, aserciones lookbehind, y la bandera `/s` (dotAll) para que el punto `.` también coincida con saltos de línea.
