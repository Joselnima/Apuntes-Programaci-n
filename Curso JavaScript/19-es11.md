# Módulo 18 - ECMAScript 11 (ES2020)

ES11 marcó otro antes y después en JavaScript con dos características que redujeron drásticamente la cantidad de código necesario para comprobar la existencia de variables: `?.` y `??`.

## 1. Optional Chaining (`?.`)

Cuando intentas leer una propiedad en cadena dentro de un objeto, si un paso intermedio es `null` o `undefined`, JavaScript lanza un error deteniendo la aplicación. `?.` devuelve `undefined` en lugar de lanzar el error.

```javascript
const usuario = {
  nombre: "María",
  direccion: { ciudad: "Bogotá" }
};

// Problema:
// console.log(usuario.contacto.telefono); // Error: Cannot read properties of undefined

// Solución ES11:
console.log(usuario.contacto?.telefono); // Devuelve undefined. No rompe la app.
```

## 2. Nullish Coalescing Operator (`??`)

Es una mejora sobre el operador lógico OR (`||`) para asignar valores por defecto. El operador `||` falla cuando el valor es "falsy" válido, como `0`, `""` o `false`. `??` solo se activa si el valor es estrictamente `null` o `undefined`.

```javascript
let velocidad = 0;

// Problema con ||
let velConfigurada = velocidad || 50; 
// Devuelve 50, ¡pero la velocidad era 0, no 50!

// Solución con ??
let velCorrecta = velocidad ?? 50; 
// Devuelve 0, porque 0 no es null ni undefined.
```

## 3. `Promise.allSettled()`

A diferencia de `Promise.all()`, que falla por completo si *una sola* promesa es rechazada, `Promise.allSettled()` espera a que *todas* terminen y te devuelve una lista con el estado final de cada una (`fulfilled` o `rejected`).

```javascript
const promesas = [
  Promise.resolve("Éxito"),
  Promise.reject("Hubo un error")
];

Promise.allSettled(promesas).then(resultados => {
  console.log(resultados);
  /*
  [
    { status: "fulfilled", value: "Éxito" },
    { status: "rejected", reason: "Hubo un error" }
  ]
  */
});
```

## 4. `BigInt` y `globalThis`
- **BigInt**: Para representar números enteros más grandes que `Number.MAX_SAFE_INTEGER` (`2^53 - 1`). Se le agrega una `n` al final: `const numeroEnorme = 9007199254740991n;`.
- **globalThis**: Ofrece una forma estándar de acceder al objeto global sin importar el entorno (`window` en navegadores, `global` en Node.js).
