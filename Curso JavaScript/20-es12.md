# Módulo 19 - ECMAScript 12 (ES2021)

ES12 introdujo reemplazos avanzados de texto, atajos de asignación lógica y nuevas formas de manipular promesas.

## 1. `String.prototype.replaceAll()`

Antes, el método `replace()` solo reemplazaba la *primera* coincidencia. Si querías reemplazarlas todas, debías usar Expresiones Regulares con la bandera global `/g`. ES12 soluciona esto con `replaceAll()`.

```javascript
const frase = "manzana, pera, manzana, uva";

// Antes (ES6):
console.log(frase.replace(/manzana/g, "sandía"));

// ES12:
console.log(frase.replaceAll("manzana", "sandía"));
// "sandía, pera, sandía, uva"
```

## 2. Operadores de Asignación Lógica (`||=`, `&&=`, `??=`)

Combinan los operadores lógicos con la asignación, reduciendo el código repetitivo, de manera similar a como lo hace `+=` o `-=`.

```javascript
let a = 1;
let b = 0;

// OR lógico (Asigna si es falsy)
a ||= 5; // a sigue siendo 1
b ||= 5; // b ahora es 5

// AND lógico (Asigna si es truthy)
let c = 10;
c &&= 20; // c ahora es 20

// Nullish Coalescing (Asigna si es null o undefined)
let d = null;
d ??= "Por defecto"; // d ahora es "Por defecto"
```

## 3. Numeric Separators (`_`)

Mejora la legibilidad de los números grandes introduciendo el guión bajo como separador de miles. El motor de JS ignora el guión bajo internamente.

```javascript
const unMillon = 1_000_000;
const presupuesto = 1_500_300.50;

console.log(unMillon === 1000000); // true
```

## 4. `Promise.any()`

Recibe una lista de promesas y se resuelve con el valor de la **primera promesa que se cumpla con éxito** (ignora las que fallan a menos que todas fallen).

```javascript
const promesas = [
  Promise.reject("Falló API 1"),
  Promise.resolve("Datos API 2"), // Ésta gana
  Promise.resolve("Datos API 3")
];

Promise.any(promesas).then(ganadora => console.log(ganadora)); 
// "Datos API 2"
```
