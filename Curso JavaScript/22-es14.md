# Módulo 21 - ECMAScript 14 (ES2023)

ES14 se enfocó fuertemente en proporcionar herramientas inmutables para arrays y búsquedas más eficientes.

## 1. Métodos Inmutables para Arrays

Un gran problema histórico de JavaScript es que métodos como `sort()`, `reverse()` y `splice()` mutan (modifican) el arreglo original. Esto causa muchos bugs indeseados. ES14 introdujo nuevas versiones inmutables que **retornan un nuevo arreglo**.

- `toSorted()`: Equivalente inmutable de `sort()`
- `toReversed()`: Equivalente inmutable de `reverse()`
- `toSpliced()`: Equivalente inmutable de `splice()`
- `with(indice, valor)`: Reemplaza un valor en un índice creando un arreglo nuevo (Equivalente inmutable de `array[indice] = valor`).

```javascript
const letras = ["z", "a", "c", "b"];

// Array.prototype.toSorted()
const ordenadas = letras.toSorted();
console.log(letras);     // ["z", "a", "c", "b"] (El original sigue intacto!)
console.log(ordenadas);  // ["a", "b", "c", "z"]

// Array.prototype.with()
const nuevasLetras = letras.with(1, "x");
console.log(nuevasLetras); // ["z", "x", "c", "b"]
```

## 2. Búsqueda desde el final (`findLast` y `findLastIndex`)

Antes, para buscar un elemento desde el final de un arreglo debías invertirlo primero (`reverse().find()`), lo cual era ineficiente y mutaba el array. Ahora existen métodos dedicados que recorren de atrás hacia adelante.

```javascript
const numeros = [5, 12, 50, 130, 44];

// Encuentra el primer número mayor a 40 (buscando desde el principio)
console.log(numeros.find(n => n > 40)); // 50

// Encuentra el primer número mayor a 40 (buscando desde el final)
console.log(numeros.findLast(n => n > 40)); // 44

// También devuelve su índice real
console.log(numeros.findLastIndex(n => n > 40)); // 4 (Posición de 44)
```

## 3. Hashbang Grammar

JavaScript ahora permite oficialmente iniciar un archivo con `#!/usr/bin/env node` para facilitar la creación de ejecutables CLI en entornos como Node.js sin que el motor de JS lance un error de sintaxis por los caracteres `#!`.
