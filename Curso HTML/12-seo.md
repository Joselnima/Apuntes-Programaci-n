# Módulo 12 - SEO básico para HTML

SEO significa optimización para motores de búsqueda. Con HTML correcto, tu página puede posicionarse mejor en Google y otros buscadores.

## Etiqueta `<title>`

```html
<title>Curso de HTML completo</title>
```

Es el texto principal que aparece en los resultados de búsqueda.

## Meta description

```html
<meta name="description" content="Curso completo de HTML con ejemplos y buenas prácticas.">
```

Describe la página y ayuda a que los buscadores la entiendan.

## Encabezados jerárquicos

```html
<h1>Curso de HTML</h1>
<h2>Contenido del curso</h2>
```

Un solo `h1` por página y subtítulos con `h2`, `h3`...

## Enlaces internos

```html
<a href="#proyecto">Ir al proyecto</a>
```

Esto ayuda a los usuarios y a los motores a navegar mejor.

## Uso correcto de etiquetas semánticas

```html
<article>
  <h2>Lección de HTML</h2>
  <p>Contenido del artículo.</p>
</article>
```

Las etiquetas semánticas mejoran la comprensión del contenido.

## Ejemplo real en `<head>`

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Aprende HTML paso a paso con ejemplos reales.">
  <title>Curso de HTML - Introducción</title>
  <link rel="canonical" href="https://www.ejemplo.com/curso-html">
</head>
```

## Buenas prácticas

- usa títulos descriptivos.
- escribe descripciones únicas.
- estructura el contenido con encabezados.
- evita contenido duplicado en la misma página.
