# 📚 Curso Completo: Fundamentos de HTML

Bienvenido a este curso de **HTML desde cero**, pensado para que aprendas cómo funciona el lenguaje de marcado que construye todas las páginas web.

Este curso está ordenado por módulos prácticos. Cada módulo tiene explicaciones claras, ejemplos reales y ejercicios simples para que aprendas haciendo.

## ¿Qué vas a aprender?

- Qué es HTML y por qué es la base de la web
- Cómo escribir la estructura correcta de cualquier página
- Cómo usar texto, imágenes, enlaces, listas y tablas
- Cómo crear formularios funcionales y avanzados
- Cómo usar metadatos y estructura avanzada en el `<head>`
- Cómo trabajar con multimedia y elementos interactivos
- Cómo aplicar etiquetas semánticas y accesibles
- Cómo dibujar gráficos con Canvas
- Cómo crear componentes reutilizables con Web Components
- Cómo usar elementos avanzados y atributos globales
- Cómo optimizar tu HTML para buscadores
- Cómo construir un proyecto práctico completo

## Cómo usar este curso

1. Lee un módulo completo.
2. Copia y prueba los ejemplos en tu editor.
3. Modifica el código y observa qué cambia.
4. Crea tu propia página con lo aprendido.

> Recomendación: aprende con ejemplos reales. No solo leas, escribe y prueba.
