# 06 - HTML desde cero

## ¿Qué aprenderás en este módulo?

En este módulo aprenderás:
- los conceptos esenciales del tema
- cómo se usan en Angular
- errores comunes
- ejemplos mentales fáciles
- una pequeña práctica guiada

---

## Explicación conceptual

Verás etiquetas, atributos, formularios, inputs, botones, listas, tablas y estructura semántica. Angular usa templates basados en HTML, así que esta base es obligatoria.

## Errores comunes

1. Aprender la sintaxis sin entender el propósito
2. Mezclar lógica de UI con lógica de negocio
3. No practicar con mini ejemplos propios
