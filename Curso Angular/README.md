# Curso de Angular 21 desde Cero 🚀

Bienvenido a este curso **completo, detallado y explicado paso a paso** de **Angular 21** pensado para alguien que **recién empieza en programación**.

Este material está escrito como si fuera un **libro práctico**: no solo te dice *qué hacer*, sino también **por qué se hace así**, **cómo pensarlo**, y **cómo conectar cada pieza**.

---

## ¿Qué vas a aprender?

En este curso vas a aprender:

- Qué es Angular y para qué sirve
- Cómo funciona la web (frontend, backend, navegador, servidor)
- HTML, CSS y TypeScript aplicado a Angular
- Cómo crear componentes, rutas, formularios y servicios
- Cómo consumir APIs
- Cómo organizar proyectos reales
- Cómo escalar una app Angular de forma profesional

---

## ¿A quién está dirigido?

Este curso es ideal si:

- Nunca programaste o recién estás comenzando
- Vienes de otro lenguaje y quieres entrar al frontend
- Quieres aprender Angular bien, desde la base
- No quieres solo copiar código, sino **entender de verdad**

---

## Recomendación de estudio

Te recomiendo seguir este orden:

1. Lee un módulo completo
2. Haz los ejercicios
3. Reescribe el código con tus palabras
4. Rompe cosas a propósito y corrígelas
5. Continúa recién cuando entiendas el porqué

> Aprender a programar no es memorizar. Es **entrenar tu forma de pensar**.
