# Curso Completo de Rust 🦀

Bienvenido al curso completo de Rust en español. Este curso está diseñado para enseñarte el lenguaje de programación Rust desde los conceptos básicos hasta temas avanzados.

## ¿Qué es Rust?

Rust es un lenguaje de programación moderno que se enfoca en tres objetivos principales:
- **Seguridad**: Previene errores comunes de programación en tiempo de compilación
- **Velocidad**: Es tan rápido como lenguajes de bajo nivel como C y C++
- **Concurrencia**: Manejo seguro de operaciones paralelas sin condiciones de carrera

## Estructura del Curso

Este curso está organizado de forma progresiva, comenzando con conceptos básicos y avanzando hacia temas más complejos:

### Fundamentos (Capítulos 1-4)
1. **01-instalacion-y-configuracion.md** - Cómo instalar y configurar Rust en Windows, macOS y Linux
2. **02-hola-mundo-y-cargo.md** - Tu primer programa y el gestor de paquetes Cargo
3. **03-conceptos-basicos.md** - Variables, tipos de datos y operaciones básicas
4. **04-funciones-y-control-de-flujo.md** - Funciones, condicionales y bucles

### El Corazón de Rust (Capítulos 5-9)
5. **05-propiedad-y-referencias.md** - El sistema de propiedad (ownership), slices y préstamo
6. **06-estructuras-y-enums.md** - Structs, enums, métodos y funciones asociadas
7. **07-manejo-de-errores.md** - Result, Option, panic y propagación de errores
8. **08-patrones-y-coincidencia.md** - Pattern matching, destructuring y guards
9. **09-colecciones.md** - Vectores, Strings y HashMap

### Características Avanzadas (Capítulos 10-15)
10. **10-genericos-traits-lifetimes.md** - Genéricos, traits y tiempos de vida
11. **11-closures-e-iteradores.md** - Programación funcional con closures e iteradores
12. **12-smart-pointers.md** - Box, Rc, RefCell, Arc y Mutex
13. **13-concurrencia.md** - Threads, canales, sincronización segura
14. **14-modulos-y-paquetes.md** - Organización de código, módulos y crates
15. **15-pruebas-automatizadas.md** - Unit tests, integration tests y benchmarks

### Aplicación Práctica (Capítulos 16-17)
16. **16-entrada-salida-y-archivos.md** - Lectura/escritura de archivos, trabajar con stdin/stdout
17. **18-buenas-practicas.md** - Patrones profesionales y mejores prácticas en Rust

## Cómo Usar Este Curso

- Lee cada capítulo en orden (aunque puedes saltar si ya tienes experiencia)
- Practica los ejemplos de código por tu cuenta
- Intenta modificar los ejemplos para entender mejor cómo funcionan
- Cuando completes un capítulo, intenta aplicar lo aprendido en pequeños ejercicios

## Requisitos Previos

- Saber programar en algún lenguaje anterior (preferiblemente C, C++, JavaScript, Python o Java)
- Tener una computadora con Windows, macOS o Linux
- Terminal/Consola instalada en tu sistema
