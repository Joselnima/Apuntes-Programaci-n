# Lección: Ejercicio 01 — Hola Mundo

Objetivos:

- Ver la estructura mínima de un programa Go con `main()`.

Descripción:

Programa de ejemplo que imprime `Hola mundo` en consola.

Archivos importantes:

- `ejercicio01.go` — contiene `func main()` e imprime un mensaje.

Cómo ejecutar (PowerShell):

```powershell
cd "e:\GO courses\ejercicio01"
go run ejercicio01.go
```

Ejemplo de salida:

- `Hola mundo`

Ejercicios sugeridos:

- Modificar para leer el nombre del usuario e imprimir `Hola, <nombre>`.
