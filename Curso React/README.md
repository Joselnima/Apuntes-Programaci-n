# Curso de React desde Cero

Bienvenido a este curso de **React desde cero**, pensado para alguien que recién empieza en programación y quiere aprender paso a paso.

Este curso está organizado en módulos cortos y progresivos. Primero aprenderás cómo funciona la web y JavaScript, luego entrarás a React, componentes, props, estado, eventos, formularios, hooks, rutas, consumo de APIs y finalmente una estructura profesional de proyecto.

> **Objetivo:** que al terminar puedas crear aplicaciones React reales por tu cuenta.

---

## ¿Qué aprenderás?

- Qué es React y para qué sirve
- Cómo funciona JavaScript moderno
- Cómo crear componentes reutilizables
- Cómo usar `props`, `state` y eventos
- Cómo renderizar listas y usar condiciones
- Cómo manejar formularios
- Cómo usar Hooks como `useState` y `useEffect`
- Cómo consumir APIs
- Cómo usar rutas con React Router
- Cómo organizar proyectos reales
- Cómo construir un proyecto final

---

## Requisitos

No necesitas experiencia previa en React.  
Solo necesitas:

- Una PC o laptop
- Visual Studio Code
- Node.js instalado
- Ganas de practicar

## Cómo estudiar este curso

Te recomiendo este orden:

1. Lee un módulo completo
2. Copia los ejemplos a tu editor
3. Modifícalos tú mismo
4. Crea mini ejercicios
5. Repite lo aprendido sin mirar

> **Regla importante:** en programación se aprende **haciendo**, no solo leyendo.

---

## Recomendación de estudio

Si recién empiezas, puedes avanzar así:

- **1 módulo por día** si tienes tiempo
- **3 módulos por semana** si estudias con calma
- **1 proyecto pequeño por cada 4 módulos**

---

## Consejo final

No intentes memorizar todo.  
Primero entiende **cómo piensa React** y luego la práctica hará el resto.
